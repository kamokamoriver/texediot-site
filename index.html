TeX EDITOR FOR WINDOWS

TexEdiot

日本語の課題・論文を、すぐ書き始められる TeX エディタ。

TeX Live を別途インストールしなくても、同梱のエンジンでコンパイルして PDF をすぐ確認できます。基本操作はオフラインで動作します。

  • 日本語の課題・論文向け
  • TeX Live 別途インストール不要
  • オフラインで動作
  • Windows 用デスクトップアプリ
ダウンロードについて

機能

現在の TexEdiot に備わっている機能です。

日本語テンプレート 4 種

課題レポート、論文・学会原稿、スライド（beamer）、複数ファイル長文のテンプレートから新規作成できます。

入力を助ける編集機能

シンタックスハイライト、コマンド補完、数式ツールバーを備えています。

保存して Ctrl+Enter でコンパイル

右側に PDF プレビュー（pdf.js）を表示し、書いた結果をすぐ確認できます。

コンパイルエラーの一覧

コンパイル時のエラーを一覧で確認できます。

必要なものを同梱

TeX エンジン（Tectonic）、日本語フォント（Noto CJK）、よく使う LaTeX パッケージを同梱。基本操作はネットワーク接続なしで動きます。

ローカルのフォルダを直接編集

PC 上のフォルダをそのまま開いて編集します。ファイルは利用者の PC に残ります。

Windows 11（x64）向けベータ版（v0.1.0-beta.1、74.2 MB）を公開しています。まだ実機の Windows では動作確認ができていません。管理者権限は不要です。

このビルドはコード署名をしていないため、初回に Microsoft Defender SmartScreen の警告が出ることがあります。その場合は「詳細情報」→「実行」を選んでください。インストーラー上の表示名は、現時点では「TexEditor」です。SHA256 は Release ページに記載しています。

未対応macOS / Linux は未対応です（対応は予定）。
対応する文書LuaLaTeX（ltjsarticle など）の文書には現時点で対応していません。同梱の Tectonic は XeTeX 系のエンジンです。
インターネット同梱範囲外の LaTeX パッケージを初回取得するときに、接続が必要になる場合があります。

FAQ

TeX Live は別途必要ですか？

基本的な日本語文書であれば、同梱の Tectonic でコンパイルできるため不要です。

オフラインで使えますか？

同梱範囲内の操作はオフラインで動作します。未同梱のパッケージを使う場合は、初回のみネットワークから取得することがあります。

対応 OS は？

現在は Windows 11（x86_64）です。Windows 10 は今後確認する予定で、macOS / Linux は未対応（予定）です。

ソースをクラウドに送信しますか？

通常の編集・コンパイルでは、文書を外部サーバーに送信しません。AI 機能は予定であり、導入する際はオプトイン（利用者が明示的に有効にする方式）にする方針です。

信頼できない .tex ファイルを開いてもよいですか？

開いてコンパイルしないでください。TeX は文書のあるフォルダ外のファイルを読める場合があります。
